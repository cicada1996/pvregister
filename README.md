# Application Description

I want to build a register that can display the relations between people who invested into solar parks and how much of that park they own and how many parks they are part of. It's in the field I currently work in so I have a lot of data to test it with. I want to be able to create new parks and be able to create new investors and then be able to delegate a percentage of a park to one investor. But since investors invest into multiple parks the app needs to be able to allow that. I also want there to be logins for my team so they can look at the investors and delegate them to new parks they inveyted in.
